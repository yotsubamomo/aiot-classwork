# 比較：D1. 重機旅遊規劃顧問 vs H. 車輛能耗偵探

> 狀態：比較完成，等待選定 ⑧ 領域（2026-10-25）
> 前提：⑨ = 實作 L2，L3 延伸；實際一人、週末；不在車上加裝東西；汽車不是自己的車，不列入考量。
> 依據：D1 的網路調查（2026-10-25）、H 的 `shortlist-a-vs-h.md` 與 `spike-ved.md`、`asset-inventory.md`。關鍵事實已抽查，標在文末「查證狀態」。

## 結論

建議選 **D1**，但和 H 一樣，先用一個週末驗證（匯出 20–30 趟 GPX 做個人配速模型）再定案。

決定性的差別：**汽車排除之後，H 已經沒有任何「自己的真實資料」**，只剩公開資料集 VED 和重播模擬；D1 的 279 趟 GPX 每一趟都是帶正確答案的真實資料，而且是你自己的嗜好。

| 面向 | D1 重機旅遊規劃顧問 | H 車輛能耗偵探 |
| --- | --- | --- |
| 使用者問題 | 「週六騎南橫，天氣路況如何？幾點出發才能天黑前回來？油夠嗎？」 | 「為什麼這個月比較耗油？天氣、路線還是開法？」 |
| 自己的真實資料 | 279 趟 GPX，每段路的實際騎乘時間就是正確答案 | 無（汽車不是自己的；機車沒有油耗資料） |
| 公開資料 | 氣象署預報與歷史觀測、公路局道路幾何（急彎、陡坡）、地形、加油站、TDX 省道即時路況 | VED（383 台車、一年，已驗證） |
| 驗證狀態 | 未驗證 | spike 已通過（R² 0.81） |
| 分析 | 個人配速模型（依曲率、坡度、道路等級、時段、天氣預測每段時間）；多元迴歸 vs 梯度提升樹 vs 導航引擎預設時間；分位數預測給範圍 | 行程油耗預測與歸因；多元迴歸 vs 梯度提升樹 |
| Agent 的角色 | 規劃 + 驗證：LLM 拆解行程需求，配速、天氣、路況、油量由工具計算和檢查 | 解釋：LLM 說明工具算出的油耗拆解 |
| 研究缺口 | LLM 旅遊規劃研究顯示模型無法自己做時間和空間計算，需要外部求解器或驗證器（TravelPlanner 最終通過率 0.6%）；ETA 研究多是城市車隊；騎士彎道速度模型樣本少、難以轉移到其他騎士；沒找到結合個人配速、台灣天氣與道路資料的 Agent | 學術上沒找到 LLM 解釋行程油耗的研究；但商業上有 Geotab Ace（車隊 GenAI 助理，能回答油耗問題） |
| 既有產品 | Calimoto、Kurviger、REVER 等能規劃彎道路線、記錄騎乘；Google Maps 有機車模式；都沒有個人配速、台灣道路阻斷、能解釋原因的風險評估 | Geotab Ace（車隊）、和泰 Drive+ 的節能表現 |
| L3 | 手機定位經 MQTT 回傳，即時更新抵達時間，遇天氣或道路狀況語音提醒；不需加裝 | 只能重播 VED |
| Deep Research | 你是騎士本人，有第一手經驗；爭議點有文獻（ABS 與風險補償、彎道速度模型能否轉移、團騎配速） | 節能駕駛效果、物理 vs 資料驅動、認證與實際落差 |
| 個人動機 | 高（嗜好） | 中 |
| 工作量（L2，粗估） | 約 6–8 個週末 | 約 8–10 個週末 |

## D1 的主要風險

| 風險 | 影響 | 對策 |
| --- | --- | --- |
| 道路阻斷沒有找到機器可讀的 API，也沒有歷史紀錄 | 「路況風險」這一塊難做即時查詢，也難回測 | TDX 省道即時路況可用；阻斷改用公路局公告或警廣事件紀錄（第三方鏡像，使用前確認條款）；先列為延伸，不當核心 |
| 只有一位騎士（n=1） | 模型不能推廣到其他人 | 在 Proposal 誠實定位為「個人化」；這也正好是和既有產品的差別 |
| 風險評分沒有正確答案 | 不能宣稱預測事故 | 規則透明（門檻取自氣象署警特報）、用歷史封路日回測、敏感度分析、案例研究 |
| 279 趟裡下雨的路段可能很少 | 天氣對配速的影響估不準 | spike 時先統計有雨的路段數 |
| 地圖比對（map matching）工作量 | 要把 GPX 對到道路才能拿到道路等級 | 先用曲率、坡度等不需比對的特徵；比對當第二步 |
| 隱私 | GPX 含住家位置 | 原始檔不進 repo；公開時裁掉頭尾、只公開衍生的路段表 |

## D1 的資料來源（已確認可用的）

| 資料 | 來源 |
| --- | --- |
| 鄉鎮預報、即時觀測、日出日落 | 氣象署開放資料 API（需免費授權碼） |
| 歷史逐時天氣 | 氣象署 API 只到最近 30 天；更早的用 CODiS（中興大學有非官方下載器） |
| 省道即時路況 | 交通部 TDX（需授權碼） |
| 道路幾何 | 公路局 GIS 開放資料：省道急彎、陡坡、速限、里程樁 |
| 地形 | 內政部 20 m 網格；注意政府開放資料平台 175240 是 DSM（含植被和建物），山區道路要找 DTM 版本 |
| 加油站 | 中油加油站資料（含經緯度、營業時間，最後更新 2024-05）；台糖有資料；台塑沒有，用 OpenStreetMap 補 |

## 建議下一步

和 H 一樣，用一個週末驗證 D1 最大的未知數：

1. 匯出 20–30 趟 GPX（山路、市區、不同季節），放在 repo 以外。
2. 清理車速、切路段、算曲率和坡度（用地形資料）、對接 CODiS 天氣。
3. 依行程分組交叉驗證：平均速度 baseline、多元迴歸、梯度提升樹，看整趟時間的誤差。
4. 統計有雨的路段數。

通過就定案 D1；不通過就退回 H（spike 已通過）。
