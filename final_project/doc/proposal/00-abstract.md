# Abstract 摘要

台灣 2025 年道路交通事故死亡 2,858 人，較前一年僅減少 3.1%，其中機車使用者占 60.9% [I1]；大型重型機車登記數至 2025 年底已達約 28 萬輛 [I4]，騎重機到山區旅遊是常見的休閒活動。然而，山區騎乘的時間、天候與補給高度相依：一般導航只提供群體平均的預估時間，不知道個別騎士在彎道與坡道的騎法 [I15]；山區午後對流集中在特定時段 [I8]，颱風豪雨也常使山區公路預警性封閉 [I6][I7]；而研究顯示大型語言模型（LLM）在需要時間與空間計算的行程規劃上並不可靠，GPT-4-Turbo 在 TravelPlanner 基準上的最終通過率僅 0.6% [I9]。

為解決上述問題，本專題提出「重機旅遊規劃顧問（Moto Touring Copilot）」，一個結合個人化資料分析與外部驗證的多 Agent 規劃系統。系統以騎士自己的 279 趟 GPX 行程訓練個人配速模型，逐段預測騎乘時間並輸出 P50 / P90 區間；由配速、天氣、路況與補給、驗證等 Agent 分工，依各路段的「預計抵達時間」整合中央氣象署預報與日照資料、交通部 TDX 路況、地形與加油站資料，並以知識庫提供有出處的領域知識；驗證 Agent 以確定性規則檢查日照、續航、天氣與路況限制，不通過即重新規劃。

評估上，本專題將以依行程分組的交叉驗證，比較個人配速模型（多元迴歸與分位數 LightGBM）與平均速度、Google Maps 兩輪車預估時間等基準；並以消融實驗比較只用 LLM、LLM 加知識庫與完整 Agent 的計畫可行率，另以歷史行程與封路紀錄進行回測與案例研究。預期個人配速模型在彎道密集的山區路段能比一般導航提供更貼近實際的時間估計，而完整 Agent 能比只用 LLM 產生更高比例的可行計畫；上述皆為待驗證的假設，本提案不含實驗結果。

**關鍵詞：** 多 Agent 系統、行程規劃、旅行時間預測、分位數迴歸、重型機車、資料分析
