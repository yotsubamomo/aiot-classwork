# Abstract 摘要

台灣 2025 年道路交通事故死亡 2,858 人，僅較前一年減少 3.1%，其中機車使用者占 60.9% [I1]；大型重型機車至 2025 年底約 28 萬輛 [I4]。山區重機旅遊的時間、天候與補給互相影響，但一般導航只提供群體平均的預估時間 [I15]，山區午後對流與颱風封路又隨時間變化 [I8][I6][I7]，而大型語言模型（LLM）單獨規劃行程並不可靠，GPT-4-Turbo 在 TravelPlanner 基準的最終通過率僅 0.6% [I9]。

本專題提出「重機旅遊規劃顧問（Moto Touring Copilot）」：以騎士自己的 279 趟 GPX 行程訓練個人配速模型並輸出 P50 / P90 區間；由配速、天氣、路況與補給、驗證等 Agent 依各路段的預計抵達時間，整合中央氣象署、交通部 TDX、地形與加油站資料，驗證不通過即重新規劃。

評估上，將以依行程分組的交叉驗證，比較個人配速模型與平均速度、Google Maps 兩輪車預估時間等基準，並以消融實驗比較只用 LLM 與完整 Agent 的計畫可行率（以獨立於 Agent 的 oracle 判定）。預期個人模型在彎道密集的山區路段更貼近實際，完整 Agent 能產生較高比例的可行計畫；以上為待驗證的假設，本提案不含實驗結果。

**關鍵詞：** 多 Agent 系統、行程規劃、旅行時間預測、分位數迴歸、重型機車、資料分析
