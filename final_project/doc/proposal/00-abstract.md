# Abstract 摘要

台灣 2025 年道路交通事故死亡 2,858 人，機車使用者占 60.9% [I1]；大型重型機車至 2025 年底登記 279,703 輛 [I4]。重機騎士出發前想知道的是「照我的騎法，幾點出發才能在天黑前回家、哪裡加油、哪一段有風險」，但一般導航只給群體平均的預估時間 [I15]，重機 App 著重路線 [I16]，大型語言模型（LLM）單獨規劃在 TravelPlanner 的最終通過率僅 0.6% [I9]。

本專題提出「重機旅遊規劃顧問（Moto Touring Copilot）」：以騎士自己的 279 趟 GPX 行程訓練個人配速模型，輸出 P50 / P90 時間；五個 Agent 依各路段的預計抵達時間整合中央氣象署、交通部 TDX 與加油站資料，由驗證規則檢查日照、續航、天氣與封路，不通過即重新規劃。

評估將比較個人配速模型與 Google Maps 兩輪車預估時間等基準，並以獨立於 Agent 的 oracle 進行消融實驗；以上成效均為待驗證的假設，本提案不含實驗結果。

**關鍵詞：** 多 Agent 系統、行程規劃、旅行時間預測、分位數迴歸、重型機車、資料分析
