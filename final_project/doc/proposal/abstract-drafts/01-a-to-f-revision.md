## A. Attention Getter

台灣 2025 年道路交通事故死亡 2,858 人，較 2024 年僅減少 92 人、降幅 3.1%，未達每年減少 7% 的政策目標；其中機車使用者死亡 1,740 人、占 60.9%，交通部也指出自摔、自撞事故比例較嚴重。[udn][roadsafety] 大型重型機車至 2025 年底登記 279,703 輛，總量仍在增加，但新領牌數已從 2023 年的 27,200 輛降到 2025 年的 15,506 輛，代表成長正在放緩，既有騎士的長程騎乘與安全更值得關注。[thb] 對重機騎士而言，週末山區旅遊最難回答的不是「怎麼走」，而是「照我的騎法，幾點出發才能在天黑前回家、中途哪裡加油、哪一段可能下雨或封路」；一次誤判，就可能變成趕路、疲勞與夜間山路騎乘。

## B. But：挑戰

現有工具各自只解決一部分。第一，一般導航提供群體平均的預估時間：Google 地圖 2018 年在台推出機車模式，以機器學習納入機車行駛速度，Google Maps 也以圖神經網路改善預估時間，但都不依個別騎士的紀錄調整，也不提供時間範圍。[google-blog][gnn-eta] 第二，Calimoto、Kurviger、REVER 等重機 App 擅長彎道路線與騎乘紀錄，卻沒有整合個人化時間、天氣與封路。[apps] 第三，山區風險具有時間性：台灣暖季午後雷雨集中在下午三到四點，南橫在 2025 年 7 月與 9 月兩度因颱風豪雨預警封閉；交通部 TDX 雖提供即時路況，但它是通用交通資料，要依「抵達該路段的時間」去查才有意義。[lin2011][cna][tdx] 第四，LLM 單獨規劃並不可靠：在須同時滿足所有硬性與常識限制的 TravelPlanner 基準上，GPT-4-Turbo 最終通過率僅 0.6%；RETAIL 基準中，最強的既有模型也只有 1.0%。[travelplanner][retail]

## C. Cure：解藥

本研究提出「重機旅遊規劃顧問（Moto Touring Copilot）」，把重機旅遊從「路線推薦」提升為個人化、可驗證、可重新規劃的出發前決策。核心設計是「LLM 負責理解與協調，確定性工具負責計算與驗證」：LLM 理解騎士需求、資訊不足時主動追問；所有時間、距離與風險都由個人配速模型、氣象與路況查詢及驗證規則產生，回答中的每個數字都必須能追溯到工具輸出。這個方向與近期研究一致：LLM-Modulo 加上外部驗證器後，GPT-4-Turbo 在 TravelPlanner 的通過率由 4.4% 提升到 20.6%；把旅遊規劃轉成可滿足性問題交給 SMT 求解器可達 93.9%；多 Agent 系統 Vaiage 拿掉外部 API 後評分由 8.5 降到 6.8（滿分 10）。[llm-modulo][smt][vaiage] ROAM 把天氣預報、實際道路距離與營業時間注入規劃提示 [roam]；本研究更進一步，依各路段的預計抵達時間查詢這些資料，並以規則驗證整份計畫。

## D. Development：方法

系統以騎士自己的 279 趟 BMW Motorrad Connected GPX（約 1 秒一點）為基礎：裁掉起訖段保護住家位置、平滑車速跳點、分離移動與停留時間後，切成約 0.5–2 km 的路段，結合彎道曲率、內政部 DTM 坡度、道路等級、急彎與陡坡標記、時段、天氣與已騎里程等特徵。配速模型直接預測路段移動時間的對數，以多元迴歸為基準、LightGBM 分位數損失輸出 P50 與 P90；整趟範圍不把各段 P90 相加，而是各段 P50 加總加上休息，再以保留行程做 conformal 校正，並推得各點的 P50／P90 預計抵達時刻。五個 Agent 分工：規劃 Agent 理解需求與分派；配速 Agent 計算各段時間與抵達時刻；天氣 Agent 查詢抵達時段的預報、警特報與民用暮光終；路況與補給 Agent 檢查 TDX 事件、加油站營業時間與續航；驗證 Agent 以日照、續航、天氣、路況、可追溯五條規則檢查計畫，不通過即重新規劃，並在候選出發時間中選擇安全餘裕最大者。

## E. Experiments：評估

評估分四個實驗。E1 配速模型：以依行程分組的交叉驗證，加上以最新行程為測試集的時間外推，比較平均速度、速限換算、Google Maps 兩輪車預估時間、多元迴歸與 LightGBM，指標為路段與整趟 MAE、MAPE 及 P90 覆蓋率。E2 消融實驗：20–30 題規劃問題，比較只用 LLM、LLM＋知識庫與完整 Agent；評分不用系統自己的規則，而是事先以獨立腳本算好的 oracle（暮光終、營業時間、管制事件、實際行程時間），指標為違規率、時間誤差、數字一致率與拒答率；另逐一拿掉配速模型、天氣、路況資料，量化各模組的貢獻。E3 以歷史封路紀錄回測風險規則；E4 以過去行程做 2–3 個完整案例。所有成效在實作前都只列為待驗證假設。

## F. Findings：預期產出

預期個人配速模型在彎道密集的山區路段，整趟時間誤差低於一般導航；P90 對實際抵達時間的覆蓋率接近 90%，可作為休息與日落前回程的緩衝；完整 Agent 對獨立 oracle 的違規率低於只用 LLM，並能較早指出不可行路段、提出延後出發或替代路線。系統輸出不是單一 ETA，而是可解釋的建議，例如「此段預計 14:20 抵達，該時段有大雨特報，建議 13:30 前通過或改走替代路線」。本研究不宣稱能降低事故率，因為目前沒有因果證據；貢獻在於一套以個人 GPX 為基礎、依抵達時間查詢風險並以規則驗證的出發前決策流程，方法可套用到任何匯入自己 GPX 的騎士。
