# DIC-1 — Personal Portal & Timekeeper

This context defines the user-facing concepts used by the DIC-1 site. Each entry gives the term the
project uses, what it means, and the wording to avoid so the vocabulary stays consistent across the
code, the tests and the documentation.

## Identity

**Display name**:
The public name shown on the site. Editable in place by the visitor and stored in the user state; it
defaults to `Momo`. On the hero it is split across two lines — the first line solid, the second
outlined — and rendered in uppercase, while the stored value keeps the original capitalisation.
_Avoid_: Full name, username, title

**Tagline**:
The single line of self-description under the display name. Also editable in place and stored in the
user state.
_Avoid_: Bio, subtitle, status

**Monogram**:
The short form of the display name shown in the top-left circle. Two or more words give the initials
of the first two words; a single word gives its first two characters. Always uppercase and always
derived from the display name, never stored separately.
_Avoid_: Avatar, logo, initials field

## Time

**Current time**:
The current wall-clock date and time in the `Asia/Taipei` time zone. Never the visitor's device time.
_Avoid_: Browser local time, device time, server time

**Time format**:
The clock notation selected by the visitor: 24-hour time by default, or 12-hour time with an explicit
AM/PM marker.
_Avoid_: Time zone, locale

**Seconds ring**:
The circular indicator beside the clock showing how far the current minute has progressed. It moves
continuously rather than in one-second steps, because the progress includes milliseconds, and it
resets to empty at the top of each minute.
_Avoid_: Progress bar, timer, countdown

**Precision readout**:
The line under the clock holding the UNIX timestamp in seconds and the current millisecond value.
_Avoid_: Epoch field, debug info

**Calendar badges**:
The two labels beside the date: the ISO 8601 week number and the day of the year. Both are computed
from the Taipei calendar date, so the hours after Taipei midnight belong to the new day even while
UTC is still on the previous one. The ISO week can belong to a different year than the date itself —
the first days of January may still be the last week of the previous year.
_Avoid_: Week of month, Julian date

**Greeting**:
The time-aware badge above the display name: morning from 05:00, afternoon from 12:00, evening from
18:00, and night from 22:00, all in Taipei time.
_Avoid_: Status message, notification

**Copied time**:
A complete text representation containing the display name, the Taipei date, the current time in the
selected format, and the `Asia/Taipei (UTC+8)` time-zone identity.
_Avoid_: Time only, device time

**Clock tick**:
The short synthesised sound played at each whole second while sound is enabled. It is generated by
the browser, never loaded from an audio file, and it is silent by default.
_Avoid_: Alarm, notification sound, audio file

## Environment

**Weather reading**:
The current temperature and condition for the selected city, fetched from a keyless public weather
service. Shown as temperature, icon and city name.
_Avoid_: Forecast, prediction

**Selected city**:
The city whose weather is displayed, chosen from Taichung, Taipei, Hsinchu, Tainan and Kaohsiung. It
affects the weather reading only; the clock is always Taipei time.
_Avoid_: Location, time zone

**Offline reading**:
The last successful weather reading for that city, shown with an explicit offline marker and the time
it was taken, when the current request fails. When no earlier reading exists the site says the
weather is unavailable rather than showing a number.
_Avoid_: Cached forecast, estimated value

## Explorer

**Drawer**:
The panel that slides in from the right holding the secondary content. The hero stays free of that
content; the drawer is opened from the hero buttons and closed with the overlay, the close button or
the Escape key.
_Avoid_: Modal, sidebar, popup

**Drawer tab**:
One of the three sections inside the drawer: Projects, About and Connect. Exactly one is visible at a
time.
_Avoid_: Page, route, screen

**Project entry**:
One item in the project catalogue, holding an id, a title, a description, and optionally a category,
a badge, technology tags and links. Entries that lack an id, title or description are dropped instead
of being displayed.
_Avoid_: Post, article, card data

**Project catalogue**:
The separate data file the project entries are loaded from at runtime. The page holds no hard-coded
project content, so adding a project means editing the catalogue only.
_Avoid_: Database, CMS, hard-coded list

## State and presentation

**User state**:
The single object holding every saved preference, serialised into browser storage under one key. It
has exactly seven fields: display name, tagline, visual theme, time format, sound setting, selected
city and Zen mode. Values that are missing, of the wrong type, or outside the allowed set fall back
to their defaults, and unknown fields are discarded.
_Avoid_: Settings, config, session

**Saved preference**:
Any field of the user state. Transient things — the current time, the toast message, the drawer's
open state and which drawer tab is showing — are deliberately not saved.
_Avoid_: Session state, cache

**Weather cache**:
The last successful weather reading per city, stored separately from the user state so it never
pollutes the seven saved preferences.
_Avoid_: Saved preference, user data

**Visual theme**:
The site's presentation selected from `Aurora`, `Minimal` and `Sunset`. A visual theme changes only
colour, background, lighting and related visual treatment; it never changes layout, information
architecture or features. `Aurora` is the dark default.
_Avoid_: Layout variant, page variant, dark mode switch

**Zen mode**:
The ambient desk-clock view: the controls, the drawer buttons and the weather are hidden, leaving the
identity, the clock and the date plus an explicit exit control. It is entered with `Z` or the Zen
button, left with `Escape` or `Z`, and it is a saved preference — a visit resumes in whichever state
it was left.
_Avoid_: Focus mode, full screen, presentation mode

**Shortcut**:
A single-key action available when no editor is open and the focus is not in a form control:
`Z` for Zen mode, `T` for the time format, `C` for copying the time, and `Escape` to close the drawer
or leave Zen mode. Keys pressed with Ctrl, Cmd or Alt are never intercepted.
_Avoid_: Hotkey combo, command
