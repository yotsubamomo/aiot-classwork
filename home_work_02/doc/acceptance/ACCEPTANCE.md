## 狀態的規則

| 狀態 | 意義 |
| --- | --- |
| PASS | 已在「核對的 subject」欄所列的 commit 上執行檢查，結果符合，證據位置可開啟。**沒有證據不得標 PASS。** |
| FAIL | 已執行，結果不符；附證據與後續處理。 |
| NOT TESTED | 沒有執行環境，或依已接受的決定延後（寫明原因，例如 pending merge）。**Best-effort 項目沒有證據時一律記 NOT TESTED，不得標 PASS。** |
