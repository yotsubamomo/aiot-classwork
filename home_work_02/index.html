探索執行

探索執行，非正式評估 每次執行探索（選取 50 Startups，或提交自訂資料集）都在瀏覽器內重新計算，結果不保存、不進報告數字，也不是作業的 Test 評估；King County 的正式分析與其數字不受影響。

自訂資料集 探索執行，非正式評估

以 CSV 的 URL 或本機 CSV 檔案提交資料（UTF-8、逗號分隔、第一列為欄名）。兩種入口取得的內容走同一條載入與分析流程；資料只在這個分頁的記憶體中計算，不上傳、不保存，換到其他 problem 後再回來需要重新提交。

只有按下「載入 URL」時，瀏覽器才對這個 URL 發出一次 GET 讀取：不帶 cookie 等憑證、不跟隨重新導向、不重試；其他操作都不發出請求。對方伺服器必須允許跨來源讀取（CORS），例如 GitHub 上的檔案請用 Raw 連結。讀取失敗時，可下載該 CSV 後改用本機檔案載入。

在瀏覽器內讀取，不發出任何請求，離線也能使用。

預設為最後一欄，必須是數值欄；改選後以同一份資料重新執行，不會重新讀取 URL。

尚未載入資料：請以 URL 或本機 CSV 檔案提交。

執行中 探索執行，非正式評估

取消在目前的候選算完後（下一個候選邊界）生效；全部候選完成後（計算共線診斷與探索 test 時）則在進行中的步驟完成時生效。取消後已算出的部分結果不顯示，只顯示「已取消」與已完成的方法數；再次執行會從頭開始。等待期間「已耗時」持續更新。執行中仍可切換問題、改選目標欄或輸入 URL；新的選取或提交會先取消目前的執行。

資料與前處理 探索執行，非正式評估

欄位型態在載入時逐格判定（每個非空儲存格都是數字的欄為數值欄）；含缺值的列整列刪除。保留或排除只用訓練列決定：類別欄在訓練列上超過 20 個層級、或任何欄在訓練列上只有一個值，就排除。Test 列不影響這些決定。

共線診斷（線性相依的欄位組）

對整個訓練集的 All-in 設計矩陣（截距＋全部編碼欄，canonical 編碼）做一次相依分析：欄依序檢查，與前面獨立欄的線性組合相同（容忍度 max(n, p)·eps）的欄形成一組線性關係。每組列出涉及的全部編碼欄、對應的 feature group 與關係式；同一組的欄彼此相依，不指認哪一欄是「問題欄」。含有完整一組相依欄的候選，設計矩陣秩不足，標為無效（INVALID_MODEL）。

各方法 CV winner 與整體 CV winner 訓練 CV 探索 test（非正式評估）

方法 CV winner：該方法有效（VALID）候選中 CV RMSE 最小者，平手取較小的 k；All-in 只有一個候選，即為自身的 winner。整體 CV winner：各方法 winner 之中 CV RMSE 最小者，平手依方法順序 All-in、Forward SFS、Backward SFS、RFE、Lasso 路徑排序。全部選擇固定之後才讀取 test 列，test 只對這些 winner 的 canonical fit 計算（canonical 子集相同的 winner 是同一個模型，只算一次）；其他候選沒有 test 數字，test 也不回饋任何選擇。在多個 k 與方法中取最小值，使 winner 的 CV 分數帶有樂觀的選擇偏誤。

全訓練集擬合（canonical fit）

CV 指標是 5 個 fold 驗證列指標的算術平均 ± 樣本標準差；每個 fold 的類別層級、基準層級（該 fold 訓練列中最先出現的層級）、one-hot 欄與 OLS 只用該 fold 的訓練列。Canonical 子集與 canonical fit 用整個訓練集。不含任何 test 資料。

Lasso 路徑（整個訓練集） 訓練 CV 的選擇依據

Exact LARS（含 Lasso 修正）在訓練列上計算：數值欄以訓練列的平均與母體標準差標準化、one-hot 欄維持 0／1、再全部置中；目標在同一批列上置中並除以其均方根、不取 log（路徑與進入順序不變，但停止與平手的數值判定與目標的單位無關），entry alpha 再乘回目標的原始尺度。Group 在任一欄第一次出現非零係數時進入，entry alpha 是該節點的 alpha，由大到小排序（相同 alpha 依 CSV 欄序）。路徑結束時若仍有 group 未進入——active set 退化、路徑走到終點，或數值停止（alpha 回升、迭代達上限）——就停在那裡，上方摘要寫出實際的停止原因：已求得的路徑段是實際結果；未進入的 group 以 CSV 欄序列在後面，只作展示，不是實際路徑、也不構成選模依據，k 超過已進入 group 數的 Lasso 候選為無效（lasso_path_degenerate）。

方法與限制 探索執行，非正式評估

探索模式與 King County 正式分析使用同一套選模語義：feature group 整組進出、Forward／Backward SFS 以 RSS、RFE 以 group 對擬合值貢獻的標準差 sd(X_g β_g)、Lasso 以 exact LARS 的進入順序、平手依 CSV 欄序、只用訓練列的編碼與 OLS 參數式預測區間。兩個 problem 在下列幾點不同：

兩個 problem 的語義差異
項目King County（正式分析）探索執行（50 Startups／自訂資料集）
目標尺度以 ln(price) 建模，預測與區間以 exp 轉回 USD（區間不對稱）目標原始尺度建模與報告，不取 log、不取 exp（目標可為負或零）
切分以房屋 id 分組的 80／20 與分組 5-fold（同一房屋不跨訓練與 test）固定 seed 的逐列 80／20 與逐列 5-fold，不分組
Lasso 退化未進入路徑的 group 依欄序補成 k = 1…18 的子集（King County 的選模語義）路徑退化或提前結束時停止（停止判定與目標的單位無關）：已求得的路徑段是實際結果，之後的 group 只作展示，k 超過的候選為無效（lasso_path_degenerate）
派生規則有：date 轉為日數、yr_renovated 拆成整修旗標與有效年份、zipcode 為類別、sqft_basement 不進模型無：每個來源欄就是一個 feature group（數值欄一欄、類別欄為訓練層級的 one-hot）；沒有日期轉換或任何資料專屬規則
Test 的地位正式的 Test evaluation，只做一次並記錄探索 test：每次執行探索時只對 CV winner 計算一次（選取候選或切換方法不會重算）、不保存，永遠不是 Test evaluation

運算預算、失敗與取消

Forward SFS、Backward SFS、RFE 與 Lasso 路徑在執行前各自估計運算量（預估 OLS 求解次數 × 訓練列數 × 編碼欄數²，只依資料大小，不依耗時）；超過該方法的預算時整個方法標「超出運算限制，未執行（SKIPPED_RESOURCE_LIMIT）」，其他方法照常執行。All-in baseline 一律最先嘗試。任一方法發生非預期的計算錯誤（含記憶體不足）時，只有該方法標為「計算失敗（FAILED）」並附訊息與環境資訊。這兩種狀態都沒有訓練 CV 指標、不會成為 winner，也不提供即時預測。執行中可取消：取消在下一個候選邊界生效，全部候選完成後則在進行中的共線診斷或探索 test 步驟完成時生效，取消後不顯示任何結果；同一份資料、同一目標欄與同一版本重跑，顯示的結果相同（耗時可不同）。

逐列切分的限制

探索模式的切分是逐列隨機的，沒有分組欄的概念。資料中若有重複的列、同一個實體的多筆紀錄（例如同一家公司或同一個人的多次觀測），或時間相依的資料，同一來源的資訊可能同時出現在訓練與 test（或同一 fold 的訓練與驗證）列，使 CV 與 test 指標過度樂觀。探索結果只供操作與比較，不代表正式研究結論。

CV winner 是在多個 k 與方法中取最小 CV RMSE 選出的，CV 分數帶有樂觀的選擇偏誤；探索 test 只對 winner 計算一次作為較獨立的估計，test 排名與 CV 排名不同時也不換模型。

F · 方法與限制

方法與限制

標示：老師要求 作業頁正文的要求；依老師補充建議 作業頁「補充」段的建議，本專案採用；專案延伸 本專案自行加入的設計，不是老師的要求。

特徵選擇方法 老師要求

作業要求必做特徵選擇。本專案以 feature group 為選擇單位（同一個 source feature 的 encoded 欄位同進同出，例如 zipcode 的全部 one-hot 欄），比較四種有 k = 1…18 路徑的方法：Forward SFS、Backward SFS、RFE、Lasso 路徑排序取前 k 個；另以單一的 All-in baseline（全部 18 個 group 的 OLS，等於路徑在 k = 18 的端點）作為基準。每個方法的子集在每個 CV fold 的訓練列上重新計算（fold-internal selection），驗證列不參與選擇；另在整個 training set 上計算一次 canonical subset，作為本頁顯示的 groups、即時預測與 Test 評估的模型。

Ridge／Lasso 是依老師補充建議加入的 metric-only 對照（alpha 只以訓練 CV 選，不參與 CV winner，不提供預測與區間）；講義的 p-value backward elimination 只列為對照，不參與 CV winner，也不在 Test 上評估。

訓練 CV／Test 協定 專案延伸

模型評估是老師的要求；下面的評估協定是本專案的設計。資料以房屋 id 分組切成 80／20 的 training 與 Test，training 內再以 id 分組成 5 個 fold，所有方法與 k 共用同一組 fold。每個方法取 CV RMSE（USD）最小的 k 為該方法的 CV winner，再從各方法 CV winner 與 All-in 中取最小者為整體 CV winner。在 18 個 k 與多個方法中取最小值，使 CV winner 的 CV 分數帶有樂觀的選擇偏誤。

全部選擇固定之後，Test 只對各方法 CV winner、All-in 與整體 CV winner（同一模型只評估一次）以及 Ridge／Lasso 各評估一次；Test 排名與 CV 排名不同時也不換模型。本頁的 KPI 與「指標 vs k」圖是訓練 CV，Test 區塊與比較表的 Test 欄只讀取匯出的結果，任何操作都不會觸發新的 Test 評估。

預測區間的統計假設 老師要求

作業要求預測圖加上信賴區間或預測區間。本專案對 OLS 子集模型在 ln(price) 尺度計算參數式 95% 預測區間 ŷ ± t·√(s²(1 + x₀ᵀ(XᵀX)⁻¹x₀))，再以 exp 轉回 USD，所以區間不對稱；點預測 exp(log 預測) 估計的是條件中位數，不是條件平均。

區間假設殘差常態、同質變異、彼此獨立，而且沒有把特徵選擇的不確定性與可能的模型誤設算進去，所以不宣稱保證 95% 的經驗涵蓋率；Test 上的經驗涵蓋率是對它的檢驗，偏離 95% 時分析原因，不自動判定失敗。涵蓋率的不確定性是假設各筆獨立的二項近似，Test 含同一房屋的重複交易，這個近似的準確度未經估計。

限制與非因果解讀 依老師補充建議

五大回歸假設的診斷與模型解釋是依老師補充建議加入（見主程式 notebook 5.6 與第 6 章，只用 training set）。古典回歸假設的診斷與預測區間的假設分開看：training 殘差的診斷不能證明或否定區間的 95% 涵蓋。

適用範圍：King County 的房屋交易；超出 training 範圍的輸入仍會計算但屬於外推，未見過的 zipcode 以基準類別計算。同一房屋重複交易的誤差可能相關（notebook 5.6.2），誤差獨立的假設對這些交易不一定成立。

係數、係數表與重要性描述的是資料中的關聯，不是因果效果：不能用來推論「改變某個特徵會讓價格改變多少」。Ridge／Lasso 只是 metric-only 對照，不提供預測。
