各方法 CV winner 與對照模型比較 訓練 CV（USD） Test 評估（USD）

整體 CV winner 是 CV RMSE 最小者（平手依方法順序 All-in、Forward SFS、Backward SFS、RFE、Lasso 路徑排序）。在 18 個 k 與多個方法中取最小值，使 CV winner 的 CV 分數帶有樂觀的選擇偏誤；Test 評估才是獨立估計，Test 排名不同時也不換模型。來源：訓練 CV 欄來自 methods[].cv、baselines.*.cv；Test 欄只讀取匯出的 test（每個被授權的模型只評估一次；canonical subset 相同的 CV winner 共用同一筆結果）。Ridge／Lasso 是 metric-only 對照（依老師補充建議）：alpha 只以訓練 CV 選、不參與 CV winner、Test 只報 MAE、MSE、RMSE、R²，沒有預測區間與涵蓋率；它們的 Test 指標只出現在本表。p-value backward 是講義方法對照，不在 Test 上評估。Adjusted R² 只對 OLS 子集模型在 log 尺度計算，Ridge／Lasso 與 CV 聚合值不適用。本頁的任何操作都不會觸發新的 Test 評估。

係數表（選配） 全訓練集擬合，R²／Adjusted R² 為 log 尺度

讀法：模型以 ln(price) 為目標、特徵為原始尺度，係數 b 表示其他欄位固定時，該欄增加 1 個單位，預測價格（exp(log 預測)，條件中位數的估計）約變動 100·(exp(b) − 1)%；zipcode 欄是相對於基準 zipcode 的差異；不同單位的特徵不能直接比較係數大小（notebook 第 6 章另列每 1 個 training 標準差的讀法）。標準誤是古典 OLS 標準誤，假設殘差同質變異與獨立，且沒有考慮特徵選擇。係數描述的是關聯，不是因果效果。

實際 vs 預測（log 刻度，逐筆 95% PI）

落入 PI（圓點） 未落入 PI（方塊） y = x 滾輪縮放、拖曳平移、游標停留讀取單筆；鍵盤：方向鍵平移、＋／－ 縮放、0 重設。全部 Test 樣本逐筆繪製，不抽樣、不聚合。

涵蓋率的不確定性是假設各筆涵蓋事件獨立的二項近似（1.96·√(p(1−p)/n_test)）。Test set 含同一房屋的重複交易，涵蓋事件不保證獨立，這個近似的準確度未經估計，本頁不陳述偏差的方向或幅度。

預測區間假設殘差常態、同質變異、獨立；特徵選擇後的推論與模型誤設都會影響名目涵蓋率，不宣稱保證 95% 的經驗涵蓋率。經驗涵蓋率偏離 95% 時需要分析原因，不自動判定失敗。

F · 方法與限制

方法與限制

標示：老師要求 作業頁正文的要求；依老師補充建議 作業頁「補充」段的建議，本專案採用；專案延伸 本專案自行加入的設計，不是老師的要求。

特徵選擇方法 老師要求

作業要求必做特徵選擇。本專案以 feature group 為選擇單位（同一個 source feature 的 encoded 欄位同進同出，例如 zipcode 的全部 one-hot 欄），比較四種有 k = 1…18 路徑的方法：Forward SFS、Backward SFS、RFE、Lasso 路徑排序取前 k 個；另以單一的 All-in baseline（全部 18 個 group 的 OLS，等於路徑在 k = 18 的端點）作為基準。每個方法的子集在每個 CV fold 的訓練列上重新計算（fold-internal selection），驗證列不參與選擇；另在整個 training set 上計算一次 canonical subset，作為本頁顯示的 groups、即時預測與 Test 評估的模型。

Ridge／Lasso 是依老師補充建議加入的 metric-only 對照（alpha 只以訓練 CV 選，不參與 CV winner，不提供預測與區間）；講義的 p-value backward elimination 只列為對照，不參與 CV winner，也不在 Test 上評估。

訓練 CV／Test 協定 專案延伸

模型評估是老師的要求；下面的評估協定是本專案的設計。資料以房屋 id 分組切成 80／20 的 training 與 Test，training 內再以 id 分組成 5 個 fold，所有方法與 k 共用同一組 fold。每個方法取 CV RMSE（USD）最小的 k 為該方法的 CV winner，再從各方法 CV winner 與 All-in 中取最小者為整體 CV winner。在 18 個 k 與多個方法中取最小值，使 CV winner 的 CV 分數帶有樂觀的選擇偏誤。

全部選擇固定之後，Test 只對各方法 CV winner、All-in 與整體 CV winner（同一模型只評估一次）以及 Ridge／Lasso 各評估一次；Test 排名與 CV 排名不同時也不換模型。本頁的 KPI 與「指標 vs k」圖是訓練 CV，Test 區塊與比較表的 Test 欄只讀取匯出的結果，任何操作都不會觸發新的 Test 評估。

預測區間的統計假設 老師要求

作業要求預測圖加上信賴區間或預測區間。本專案對 OLS 子集模型在 ln(price) 尺度計算參數式 95% 預測區間 ŷ ± t·√(s²(1 + x₀ᵀ(XᵀX)⁻¹x₀))，再以 exp 轉回 USD，所以區間不對稱；點預測 exp(log 預測) 估計的是條件中位數，不是條件平均。

區間假設殘差常態、同質變異、彼此獨立，而且沒有把特徵選擇的不確定性與可能的模型誤設算進去，所以不宣稱保證 95% 的經驗涵蓋率；Test 上的經驗涵蓋率是對它的檢驗，偏離 95% 時分析原因，不自動判定失敗。涵蓋率的不確定性是假設各筆獨立的二項近似，Test 含同一房屋的重複交易，這個近似的準確度未經估計。

限制與非因果解讀 依老師補充建議

五大回歸假設的診斷與模型解釋是依老師補充建議加入（見主程式 notebook 5.6 與第 6 章，只用 training set）。古典回歸假設的診斷與預測區間的假設分開看：training 殘差的診斷不能證明或否定區間的 95% 涵蓋。

適用範圍：King County 的房屋交易；超出 training 範圍的輸入仍會計算但屬於外推，未見過的 zipcode 以基準類別計算。同一房屋重複交易的誤差可能相關（notebook 5.6.2），誤差獨立的假設對這些交易不一定成立。

係數、係數表與重要性描述的是資料中的關聯，不是因果效果：不能用來推論「改變某個特徵會讓價格改變多少」。Ridge／Lasso 只是 metric-only 對照，不提供預測。
