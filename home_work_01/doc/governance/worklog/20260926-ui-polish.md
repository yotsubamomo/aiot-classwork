## Implementation summary

只改 `static/styles.css`（結構性分組全部以 CSS 達成，**`static/index.html` 與 `static/app.js` 零變更**）：

1. **Token 統一**：新增背景層（`--bg-top`、`--bg-glow`、`--bg-glow-2`）、elevation（`--shadow-sm`／`--shadow`／`--shadow-hero`）、radius（`--radius` 16／`--radius-md` 12／`--radius-sm` 10）、spacing（`--gap`、`--pad`）與 hero token（`--hero-top`、`--hero-bottom`、`--hero-border`）；dark block 同步。`--band-*`、`--obs-pill-*`、`--obs-stale-*`、`--map-*` 未改（其關係由測試釘住）。
2. **背景**：`body` 改為兩層 radial glow＋縱向線性漸層（navy-tinted 頂部淡入淺灰），`background-repeat: no-repeat`；純 CSS gradient，無 `url()`。
3. **Container**：`.page` `max-width` 1120 → **1440 px**，置中；gutter `clamp(16px, 3vw, 40px)`。
4. **Masthead**：≥1024 px 以 grid 將 eyebrow＋H1 放左、lead 放右（同字串、同 DOM），高度由 ~165 px 壓到 ~100 px；lead 在桌機維持 16 px（V-1）。
5. **Map hero**：整張 `.map-card` 在淺／深色 scheme 皆為深色（與 P-1「地圖區永遠深色」一致並延伸到 card）；做法是在 `.map-card` 內把頁面 token（`--surface`、`--border`、`--text`、`--muted`、`--heading`、`--accent`、`--toggle-on-*`）重新指向 map palette，heading／mode switch／caption／notes 因此自動跟隨，不需逐元素設色。Hero 用 `--shadow-hero`。
6. **地圖高度**：`.map` 桌機 560 → **640 px**（固定；平板 440、手機 360 不變）；桌機 Now panel（釘住 block 內）`height: 562px` → **`642px`**（= 640 map ＋ map-frame 上下 1 px border，與原 560/562 同關係）。`grid-template-columns: 360px minmax(0, 1fr)`、`overflow: hidden`、grid rows 等釘住值不變。
7. **Forecast section（Composition A）**：`#dashboard` 改成單一 grid；≥1024 px 為 `minmax(0, 1.75fr) minmax(340px, 1fr)`，areas `head head / sum table / chart table`，`.grid` 以 `display: contents` 讓 chart／table card 直接進 section grid，table 跨兩列 → 兩欄底線對齊；table card 為 flex column、表格 `height: 100%`，7 列平分欄高。<1024 px 單欄：header → summary → chart → table（原 900–1023 px 的 3fr/2fr 並排取消，符合 brief §5）。`.controls` 變成精簡 header bar（≥561 px label 與 select 同列、caption 置右）。Chart 較大：chart 寬度由 `app.js` 既有規則（`H = W × 0.46`）決定，左欄變寬即自動變大，不改 JS。
8. **Card 細節**：`.card` radius 16／padding 20／`--shadow`；stat tile radius 12＋`--shadow-sm`；state 盒 radius 12；`.select` `min-height: 44px`；表格 zebra（`--surface-2`）；section heading weight 650。
9. **README**：唯一變為不實的敘述（「about 170 px of a 360–560 px tall map」）改為 360–640 px。`:701-719`（layout）、`:838-856`（地圖深色、vendored Leaflet）仍為真，未改。

### Browser 驗證儀器的 HOW 調整（非產品檔；AC 語義不變）

1. **`tests/check_fence_browser.py`**：依 brief「add 1440 to the viewport list」新增 `f1-1440`（desktop panel F-1）與 `desktop-1440`（density、desktop panel、states）兩組計畫。
2. **`tests/check_refresh_browser.py` `isolation()`（AC-V2-09(b)「map still pans and zooms」）**：原儀器在開場 zoom 7 按一次 `ArrowRight` 判定 pan。**根因**：開場 zoom 7 時，視窗在兩軸都大於圍欄範圍 E，Leaflet `maxBounds` 依 R-V2-MAP-1 (ii) 把 E 置中，東向 pan 本來就無處可去——baseline（`main`，644×560）只因置中的 1 px 捨入回彈而得到 `translate3d(-1px, 0, 0)`（probe 實測），新版（787×640）剛好完全置中得到 0 px。產品行為兩者相同（開場視野都不能 pan；zoom ≥8 皆可 pan）。**調整**：先 zoom-in（驗 zoomed）、再 `ArrowRight`（驗 panned）、再 zoom-out；判準與 AC 文意不變。
3. **`tests/check_radar_browser.py` `rendered()`（AC-V2-19 rendered pixels）**：原儀器 capture 時隱藏 marker／tooltip／on-map notice。**根因**：新版 1280 px 地圖較寬，zoom 7 時雷達產品 NE 角的參考方塊（26.5°N, 124.0°E）首次落在畫面內，且正好位於 zoom 按鈕下方（約 x 734、y 55），被 UI 遮住而「找不到」；baseline 644 px 地圖時該點在畫面外。**調整**：capture 時一併隱藏 `.leaflet-control-container`（與既有隱藏 marker 同性質）；1 km 對齊 oracle 不變。
4. **新增 `tests/check_ui_polish_browser.py`**：本 WI 的幾何／截圖儀器（不被 pytest 收集，沿用既有 driver 與 #37 rig、sentinel key、零網路）。**注意**：brief 的檔案清單未列此新檔；它只含驗證，不影響產品，列此揭露。
